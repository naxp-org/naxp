Define mappings for alphanumeric codes using expressions.

naxp allows you to map alphanumeric codes, e.g. postcodes, to a numerical index unambiguously and safely across multiple coding languages and hardware platforms.

A quick tour of naxp

Characters

Every printable ASCII character stands for itself, apart from twelve that carry syntactic meaning. Those take a backslash: ! # ( ) - ? [ \ ] { | }. Whitespace in a naxp is ignored, so space an expression out to make it readable, and write \s where you mean a space.

Athe character A
\-a literal hyphen
\sa space
\A{2}\-\9{4}
matches PO-1234

Character classes

Four block escapes cover the sets you need most often.

\9a digit
\Aa capital
\aa lower case letter
\Xa digit or a capital
\A\A\9
matches EC4

Character sets

Square brackets take the union of what is inside. Each item is a single character, an inclusive range written lowest first, or a block escape.

[AEIOU]any listed character
[A-F]an inclusive range
[\9A-F]a hexadecimal digit
\#[\9A-F]{6}
matches #FF00AA

Digits ranges

A digits range stands for the decimal representations of the numbers between two bounds. The digits you write fix the widths generated, so leading zeros in the lower bound set a minimum width.

#[1-9999]1 to 9999, one to four digits
#[01-31]01 to 31, always two digits
\A{2}#[1-9999]
matches BA2490

Alternatives and groups

A vertical bar separates alternatives. Parentheses group, which matters because a postfix binds to the single item before it.

x|yeither x or y
(x)grouping
(EC|WC)\9\A
matches EC4M

Optional

A question mark makes one item optional. Which way it went is part of the encoding, so the two cases take different values.

x?x or nothing
\A\A?\9
matches EC4 and E4

Intervals

An interval repeats one item a fixed number of times, or a range of times. There is no unbounded form, because a naxp must have a finite count of values.

x{3}exactly three of x
x{2,4}two to four of x
\A{3}
matches LHR

Replaceable

A replaceable element matches as usual, but which string it matched is not part of the encoding. Every match takes the same value, and the replacement is what gets printed when text is rebuilt from an integer.

x!yanything x matches, printed as y
x!!x or nothing, printed as x
x!?x or nothing, printed as nothing
\A\A?\9\X?\s!!\9\A\A
matches EC4M 8AD and EC4M8AD

The whole grammar

The specification defines the syntax and the rules a naxp must satisfy to be well formed. Version 1 will be the first release; it is still being written and is not published yet.
